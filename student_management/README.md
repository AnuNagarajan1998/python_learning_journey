# Student Management System

## Overview

The Student Management System is a console-based Python application developed to practice Python programming and Object-Oriented Programming (OOP) concepts.

The application allows student records to be created, stored, retrieved, and managed through a menu-driven interface. Student information is persisted using **File I/O**, so the data can be stored in a file instead of existing only while the program is running.

This project was developed as part of my Python learning journey to gain practical experience in building a complete application using classes, objects, methods, file handling, and program flow.

---

## Features

- Add student details
- Store student records
- Display student information
- Search/manage student records
- Read student information from a file
- Write student information to a file
- Maintain student data using File I/O
- Menu-driven console interface
- Input handling and validation
- Perform operations using classes and methods
