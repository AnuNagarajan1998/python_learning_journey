# Bank Management System

## Overview

The Bank Management System is a Python-based console application developed to simulate basic banking operations.

The project was built using **Object-Oriented Programming (OOP)** principles to model different types of bank accounts and their operations.

The application allows users to create Savings and Current accounts, log in using their account number and PIN, check their balance, deposit money, withdraw money, view transaction history, and log out.

This project was developed as part of my Python learning journey to gain practical experience in designing a real-world application using classes, objects, inheritance, abstraction, polymorphism, encapsulation, methods, and program flow.

---

# Features

- Create a bank account
- Create Savings Account
- Create Current Account
- Automatically generate account numbers
- Set a PIN for an account
- Login using account number and PIN
- Validate PIN format
- Check account balance
- Deposit money
- Withdraw money
- Maintain transaction records
- View mini statements
- Calculate account-specific interest
- Logout from the account
- Menu-driven banking interface
